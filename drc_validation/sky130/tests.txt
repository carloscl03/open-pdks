# Rule tests for the sky130 magic tech file.
#
# Each line maps a rule of rules.csv (parsed from the SkyWater design rule
# manual) to a test that run_magic_rule_tests.py can draw.  The value of
# the rule is always taken from rules.csv, never from this file.
#
#   rule        kind    layer     [in=<well layer>]
#
# kind:
#   width   a single rectangle of the given width
#   space   two rectangles at the given spacing
#   area    a single rectangle of the given area
#   hole    a ring around a square hole of the given area
#
# "in=" draws the test inside a large rectangle of that layer (pdiff
# needs an nwell).  A rule may be listed more than once for different
# layers; the test name then gets a "/layer" suffix.

nwell.1     width   nwell
nwell.2a    space   nwell

difftap.1   width   pdiff     in=nwell
